# Agent-Runner-Kit

An Obsidian and AI-assisted framework for endurance training: keep goals, plans, activity logs, athlete feedback, weekly reviews and research in a private Markdown vault. COROS and Intervals.icu connections are optional.

[中文 documentation](README.md) · [日本語](README_JA.md) · [MIT License](LICENSE)

Copy `03_Vault_Skeleton/` to a **private** vault, read [setup](02_MCP_Setup/README.md), and use the [templates](03_Vault_Skeleton/05_Templates/README.md). The Chinese documentation is currently the most complete. Dataview is optional. The included COROS direct script is an experimental one-shot CLI, not a stdio MCP server; use the current [official COROS integration guide](https://github.com/coroslab/COROS-MCP) for setup.

AI can assist with records, evidence and planning, but can make errors and cannot diagnose injuries or guarantee safety. Athlete feedback and professional review matter. Separate measured data, self-report, plans and inference; leave unknown values blank. De-duplicate synced activities and do not add loads from different platform models. FTP or heart-rate zones require individual context.

Never publish personal training records, location/health data, FIT files, credentials or tokens. Review private vault synchronization and backups before sharing.
