## 📊 近期训练记录流 (最近 10 次训练)

```dataview
TABLE WITHOUT ID
  file.link as "训练日志",
  date as "日期",
  type as "类型",
  choice(distance_km > 0, distance_km + " km", "--") as "距离",
  choice(avg_pace != null, avg_pace, "--") as "平均配速",
  choice(avg_hr > 0, avg_hr + " bpm", "--") as "平均心率",
  choice(training_load > 0, training_load, choice(tss > 0, tss, 0)) as "负荷",
  choice(rpe != null, rpe, "--") as "RPE",
  choice(knee_status == 0, "🟢 正常", choice(knee_status == 1, "🟡 微酸", "🔴 预警")) as "关节状态"
FROM "01_Seasons"
WHERE date != null
SORT date desc
LIMIT 10
```

## 📈 动态训练负荷与指标聚合 (DataviewJS)

```dataviewjs
// 自动扫描 01_Seasons 下所有有效日志
const pages = dv.pages('"01_Seasons"')
  .where(p => p.date && (p.training_load > 0 || p.distance_km > 0 || p.tss > 0))
  .sort(p => p.date, 'desc');

let totalRunKm = 0;
let totalBikeKm = 0;
let totalLoad = 0;
let count = pages.length;

pages.forEach(p => {
  if (p.sport === 'cycling' || p.type?.includes('骑行')) {
    totalBikeKm += (p.distance_km || 0);
  } else {
    totalRunKm += (p.distance_km || 0);
  }
  totalLoad += (p.training_load || p.tss || 0);
});

dv.paragraph(`> **累计记录统计**：已完成训练 **${count}** 堂课 ｜ 累计跑步 **${totalRunKm.toFixed(1)}** km ｜ 累计骑行 **${totalBikeKm.toFixed(1)}** km ｜ 累计负荷 **${totalLoad.toFixed(0)}**`);
```

## 💡 执教提示与健康备忘

* **晨起自检**：若连续 2 天夜间睡眠 HRV 显著偏低，请主动向 AI 提出调整今日课表；
* **关节痛感追踪**：记录中若出现 `knee_status >= 2`，系统将自动高亮警示并提示转为低冲击骑行或静蹲；
* **周日复盘**：跑完周末长距离后，唤起 AI 执行“周末全量复盘并排定下周课表”。
