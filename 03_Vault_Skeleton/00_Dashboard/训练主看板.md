## 近期训练日志

需要安装并启用 Obsidian 社区插件 Dataview；未安装时不影响 Markdown 阅读。下面只是日志索引，不代表原始平台已经同步或核对。

```dataview
TABLE date AS "日期", sport AS "项目", type AS "训练", distance_km AS "距离 km", duration_min AS "分钟", rpe AS "RPE", feeling AS "感受"
FROM "01_Seasons"
WHERE contains(file.folder, "/Logs") AND date != null
SORT date DESC
LIMIT 15
```

## 使用与统计

周末链接当前赛季 `Reviews/` 的周复盘。跑步公里、骑行分钟及虚拟公里分列；先核对活动 ID 后再结算。**本页不自动跨平台去重或合并负荷**，没有记录也不代表休息。详见 [[04_Tools/双数据源活动归并与日志规则]]。

档案、赛季目录、日志、活动导出和账号凭证可能包含个人信息；公开仓库前逐项核查。此骨架的示例全部为虚构数据，不代表已完成训练。
