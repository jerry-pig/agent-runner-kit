# 💬 日常提示示例

- **记录跑步**：“查询我今天 COROS 的活动，核对活动 ID 与已同步副本，按跑步模板写日志；缺少的主观感受请留空。”
- **记录骑行**：“查询今天 Intervals.icu 的骑行，按真实活动 ID 写日志，展示实际分段，并注明 FTP 是否验证。”
- **复盘一周**：“按原始活动去重，分别汇总跑步公里、骑行分钟与体感，填写本周复盘，标出数据缺口并提出下周预案。”
- **身体不适**：“我出现了以下症状及变化，请帮我整理训练背景、调整预案，并说明何时需要专业评估。”
- **查询文献**：“查原始论文或系统综述，解释研究人群、结果与局限，再讨论对我的适用性。”

服务可用性由实际环境决定，AI 应如实报告接口、数据和工具权限；向手表或外部服务写入需用户明确授权。
