# 模板使用说明

- 跑步、骑行、双练分别使用对应日志模板；真实活动 ID、项目、来源、日期和缺失值优先填写。图表使用已核对的真实分段。
- 新建周计划后，将日志的 `target_cycle` 改为实际课表链接；周末在 `Reviews/` 使用独立周复盘模板，结合运动员体感与原始活动去重。
- 双练综合页和单项日志不要同时作为计量来源；参见 [[04_Tools/双数据源活动归并与日志规则]]。模板不自动去重或同步。
- Obsidian 核心 Templates 支持 `{{date}}`、`{{title}}`；`{{cycle_id}}`、`{{start_date}}`、`{{end_date}}` 等自定义占位符需手动替换或使用自选插件。未知值留空，不填虚构的 0。
- 训练与证据边界见 [[02_Knowledge/00_训练证据与使用边界]]。个人数据和 API 凭证不得提交到公开仓库。
