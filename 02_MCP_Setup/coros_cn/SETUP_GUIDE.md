# COROS 接入说明

优先使用 [COROS 官方 MCP 文档](https://github.com/coroslab/COROS-MCP)提供的客户端连接或登录流程；区域、认证与工具能力以官方当前文档和实际服务返回为准。为保护隐私，在可信客户端完成授权，不把 token 或登录信息放进日志和公开仓库。

本目录的 `coros-direct.js` 是实验性的**命令行单次调用工具**，依赖特定本地 token 缓存，并使用脚本里固定的网络连接方式。地址、网络、认证状态和服务协议可能变化；文件存在不等于凭证有效，也不保证自动刷新。它不提供 MCP stdio 服务，不能当作 `mcpServers` 的服务启动命令。仅在理解本地网络配置并有权限的前提下使用；优先查阅当前官方连接方式。

首次验证应选只读功能，例如查询设备或指定日期活动；工具实际名称和参数以已连接服务动态发现的定义为准。401 可能与认证或区域有关，也可能有其他原因；不要把网络异常当成账号中没有训练记录。
