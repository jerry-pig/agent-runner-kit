# 🔌 02_MCP_Setup: 穿戴硬件与耐力数据平台接驳总览

> 本目录提供针对两大主流数据源的完整配置方案与脚本：
> 1. **`coros_cn/`**：解决高驰大陆区用户在本地代理/VPN环境下稳定调用的专用直连方案。
> 2. **`intervals_icu/`**：解决室内骑行台（MyWhoosh / ThinkRider 等）跨平台功率与 TSS 负荷量化方案。
> 3. **`agent_mcp_config.json`**：各大主流 AI 客户端（Cursor、Antigravity、Claude Desktop、Cline）的通用配置片段。

请根据你的实际穿戴设备，优先阅读对应子目录下的 `SETUP_GUIDE.md` 进行配置。
