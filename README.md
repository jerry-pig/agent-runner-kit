# 🏃 Agent-Runner-Kit

**Obsidian ＋ AI 训练助理的耐力训练工作框架**。用本地 Markdown 把训练计划、活动记录、运动员体感、周复盘与运动科学资料连接起来；COROS 和 Intervals.icu 可按需接入。

[English](README_EN.md) · [日本語](README_JA.md) · [MIT License](LICENSE)

## 能做什么

1. 记录目标、训练背景、时间资源、环境、成绩和需要观察的身体反馈。
2. 读取已授权的数据源，核对来源及重复活动，生成跑步、骑行、双练、力量或游泳日志。
3. 对照计划与实际、汇总每周跑量和骑行时长，结合主观状态提出可调整的下周预案。
4. 记录长期训练假设、参考文献及其局限。图表只使用真实、有来源的数据。

AI 有助于整理与提出方案，也会遗漏信息或给出错误推断；它无法远程诊断伤病或保证训练安全。疼痛加重、改变动作或持续异常时，停止刺激性训练并考虑运动医学／康复专业评估。运动员始终参与决策，需要时请教练或专业人员审阅。参见 [训练证据与使用边界](03_Vault_Skeleton/02_Knowledge/00_训练证据与使用边界.md)。

## 开始使用

1. 阅读 [AI 启动指南](AGENT_BOOTSTRAP.md)和[使用手册](04_User_Manual.md)。
2. 将 `03_Vault_Skeleton/` **复制到自己的私有目录**，在 Obsidian 中打开副本；填写档案并按需建立赛季。
3. 按需使用 [COROS 官方连接方式](02_MCP_Setup/coros_cn/SETUP_GUIDE.md)与 [Intervals.icu 指南](02_MCP_Setup/intervals_icu/SETUP_GUIDE.md)。本项目的 COROS 直连脚本是实验性 CLI，不是 MCP 服务；参考文档以实际版本为准。
4. 按 [模板说明](03_Vault_Skeleton/05_Templates/README.md)建日志、周计划与周复盘。Dataview 是可选社区插件；没有插件仍可阅读 Markdown。

## 数据和使用原则

- 跑步和骑行分开统计；跨平台同步副本按活动 ID／时间核对，**模板和看板不会自动去重**。
- 设备值、运动员自述、计划与 AI 推断分别标注。缺失信息保持未知；模型指标不是伤病或恢复诊断。
- 不将固定心率、疼痛评分、训练量或流派当成普适处方。跑步与骑行分别评估强度；未校准的 FTP 不应当成实测阈值。
- 运动记录可能包含健康、位置及账号信息。**不要将个人 vault、原始 FIT 文件、API 密钥或 token 发布到公开仓库**。本地 Markdown 也可能被同步工具上传；检查自己的同步与备份设置。
- 读取外部数据和写入手表的可用性取决于客户端、授权、网络及供应商政策；向外部服务写入应有用户明确指令。
