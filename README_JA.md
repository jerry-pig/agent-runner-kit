# Agent-Runner-Kit

Obsidian と AI を使い、目標、計画、運動記録、主観的な体調、週次レビューと研究資料を整理する持久系トレーニング用の枠組みです。COROS と Intervals.icu の接続は任意です。

[中文 documentation](README.md) · [English](README_EN.md) · [MIT License](LICENSE)

`03_Vault_Skeleton/` を**非公開の保管場所**へコピーし、[接続ガイド](02_MCP_Setup/README.md)と[テンプレート](03_Vault_Skeleton/05_Templates/README.md)を参照してください。詳しい説明は現在中国語が中心です。Dataview は任意です。付属の COROS スクリプトは実験的な一回実行 CLI であり、stdio MCP サーバーではありません。接続は [COROS 公式ガイド](https://github.com/coroslab/COROS-MCP)を確認してください。

AI は記録や計画を補助できますが、誤りもあり、傷害の診断や安全の保証はできません。実測値、本人の感想、計画と推測を区別し、不明な値は空欄にします。同期済み活動は重複を確認し、異なるサービスの負荷モデルを直接合算しません。

個人の運動・健康・位置情報、FIT ファイル、API キーやトークンを公開リポジトリに保存しないでください。
