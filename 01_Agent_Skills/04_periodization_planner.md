# 周期与周计划

以运动员当前训练、近期负荷、赛事目标、恢复、时间、气候和个人偏好为依据，先写阶段目标，再给可执行的周计划和每日缩短／取消入口；定期用实际训练与反馈更新。计划与实际分开，缺少必要信息时标明假设。

- 轻松有氧、跑步专项、力量及骑行按目标和耐受组合；不强制套用 80/20、固定每周增量、世界级跑量或双阈值。
- 跑步和骑行分别定强度。一天双练要结合既有经验、间隔、饮食、睡眠及次日反应，避免为形式牺牲恢复。
- HRV、负荷比、静息心率、单次疼痛评分均为线索，不以固定阈值诊断或自动套公式增减训练。疼痛加重、改变步态或持续异常时停止刺激性训练并考虑专业评估。
- 周末用 `05_Templates/周复盘模板.md` 比较实际训练、恢复及下周选择；缺失数据保持未知。
- 向外部日历／手表写入之前，核对设备支持的实际工具与格式，并取得用户对该写入的明确授权；本文不提供未经验证的 JSON 课表。
