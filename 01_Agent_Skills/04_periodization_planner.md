# 📅 Agent Skill 04: 周期化课表规划与自适应微调

> **适用场景**：每周日制定下周微周期（Microcycle）课表，或在跑者体感不适/HRV 偏低时动态微调课表，以及直推课表到手表。

---

## 🏛️ 周期化课表设计原则 (TID 训练强度分布)

1. **极化 / 金字塔比例（80/20 原则）**：
   - 75% ~ 80%：低强度有氧基础跑（Zone 1 ~ Zone 2，E 配速，轻松对话跑）；
   - 15% ~ 20%：乳酸阈值 / 专项间歇课（T 配速 / I 配速 / 微间歇）；
   - 避免掉入“垃圾中等强度陷阱”（慢跑不够慢、快跑不够快）。
2. **微周期黄金节奏**：
   - 周一：主动恢复或完全休息（骑行台排酸 / Keith Baar 等长腱骨重塑）；
   - 周二：**质量课 1**（乳酸门槛巡航间歇 或 Billat 30-30 微间歇）；
   - 周三：轻松有氧慢跑 (E 跑)；
   - 周四：中等距离平稳有氧或力量交叉；
   - 周五：轻松慢跑 + 4~6 组 Strides 跨步冲刺（神经肌肉激活）；
   - 周六：**质量课 2 / 长距离耐力跑 (LSD)**；
   - 周日：完全休息或低心率骑行台排酸。

---

## ⚡ 动态微调触发矩阵 (自适应规则)

| 触发信号 | 生理诊断 | Agent 课表干预动作 |
| :--- | :--- | :--- |
| **夜间 HRV 连续 2 天低点** | 交感神经疲劳，自主神经未恢复 | 将当日质量课**降级**为 Zone 1 纯排酸慢跑 30-40 分钟或休整 |
| **`knee_status` 或关节痛感 $\ge 2$** | 下肢肌腱/软骨微损伤预警 | **立即停跑**，改为室内骑行台低阻力 45 分钟 + 等长抗阻练习 |
| **急性慢性负荷比 (ACWR) > 1.5** | 训练负荷暴增，伤病风险极高 | 削减本周末 LSD 跑量 20%~30%，冻结下周增量 |
| **晨脉平稳、HRV 良好、RPE 持续低位** | 适应良好，超量恢复充分 | 维持原定课表，或微调配速提升 2~3 秒/公里 |

---

## ⌚ 课表一键直推手表 (COROS MCP)

当设计好结构化课表（如间歇跑：热身 2km + 5组(1km T配速 + 400m 慢跑) + 冷身 2km）后，可通过 MCP 的 `createScheduledWorkout` 工具直接推送到手表日历：

```json
{
  "workoutName": "5x1km 门槛巡航间歇",
  "sportType": 100,
  "date": "20261022",
  "steps": [
    { "type": "warmup", "distance": 2000, "targetPace": "05:00-05:20" },
    { "type": "repeats", "repeatCount": 5, "workDistance": 1000, "targetPace": "03:55-04:05", "restDistance": 400, "restType": "jog" },
    { "type": "cooldown", "distance": 2000, "targetPace": "05:15-05:45" }
  ]
}
```
手表端将在设定日期自动响铃提醒，并在跑步过程中进行实时配速区间震动提醒，实现“AI 设计 $\to$ 手表执行”的无缝闭环！
