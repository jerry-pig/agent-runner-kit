# COROS 数据摄入

1. 确定当地日期，查询 COROS 原始活动列表；跨午夜活动同时检查相邻日期。保留 labelId、开始时间、项目、时长和单位。
2. 按需查看活动详情及逐圈数据。平台没有提供的指标、伤痛与 RPE 保持未知；不能从心率或设备评分推断主观感受。
3. 与 Intervals.icu 同步记录按 ID／时间／项目核对，无法确认的副本标 `needs_review`。完整规则见 `03_Vault_Skeleton/04_Tools/双数据源活动归并与日志规则.md`。
4. 使用 `05_Templates/训练日志模板.md` 创建日志，填入正确 `target_cycle`、来源与 ID；描述真实分段并对照计划，设备异常时记录来源差异。
5. 如果接口未连接或无记录，区分授权错误、网络错误、尚未同步和确实无活动；可以记录运动员自述，但不得伪造平台数值。

`coros-direct.js` 是单次调用 CLI，**不是可注册的 stdio MCP 服务**；工具名称与参数以当前实际环境和官方文档为准。不要输出 access token。
