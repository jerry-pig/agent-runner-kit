# Intervals.icu 骑行与多项目数据

以 Intervals.icu 中的骑行活动为来源，核对实际活动 ID、当地开始时间、时长、虚拟距离、功率、踏频、心率与模型负荷。多段连续活动分别记录；FIT 文件名可能重复，不是唯一键。跨平台同步副本需按 ID／时间核对，见 `03_Vault_Skeleton/04_Tools/双数据源活动归并与日志规则.md`。

使用 `05_Templates/骑行训练日志模板.md` 或双练模板：标明 FTP 是实测还是平台默认；FTP 未校准时，功率区和强度系数只作平台分类。骑行心率与跑步阈值不能直接互套；记录呼吸、RPE、腿部、室内散热及次日反馈。

API Basic Auth 用户名为字面 `API_KEY`、密码为个人 API key。密钥保存在本机受保护配置，不写入聊天、仓库或输出。仅当工具实际可用时报告已连接；有的第三方数据源可能受供应商 API 限制，应保留缺失而非猜测。
